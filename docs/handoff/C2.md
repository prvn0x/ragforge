## Requests for the Phase 2 integrator
1. **Wire the worker dispatch (module A):** for kinds in `services.sync.policy.SYNC_KINDS`, call `run_sync_job(lease, deps)`. It already calls `fail`/`complete`; the worker must NOT call them again for these kinds. `asyncio.CancelledError` propagates, so the worker should `release` the job.
2. **bootstrap.py (worker):** `SyncDeps(tx=SqlTransactionManager(worker_engine), queue=<A JobQueue>, store=SqlSyncStore(), index=<B DocumentIndex>, chunker=<B>, embedders=<B registry>, secrets=EnvelopeSecretBox, connectors=<C1 ConnectorFactory>, blobs=LocalBlobStore(settings.upload_dir), parser=SandboxedDocumentParser())`.
3. **Module C1 (Notion connector):** implement `services.sync.ports.ConnectorFactory.open(*, connector_id, kind, token, config)`. It returns an **async context manager** yielding a `SourceConnector`, so the connector can close its HTTP client. Contract details:
   - `fetch()` must return `doc.ref.external_id == requested`, `doc.fetched_at` set (Notion `Date` header − 60 s), and `doc.ref.last_edited_time`.
   - Raise `domain.errors.NotFound` on a definitive 404 (the job goes dead). Raise `UpstreamRateLimited(retry_after)` on 429.
   - Never put the token in exception messages: `last_error` shows the exception class plus a 500-char message.
   - `list_changed(since)`: ~~C2 already subtracts the 5-min overlap~~ **Superseded in Phase 2a (decision a, handoff C1 request 2):** `SyncPolicy.cursor_overlap` now defaults to `timedelta(0)` and sync passes the stored cursor through unchanged. The connector owns the 5-min overlap (ADR-0007), so it is applied exactly once.
4. **Module E (API):**
   - `POST /v1/collections/{id}/files` → `services.sync.uploads.accept_upload(...)`. It enforces the 50 MB cap and cleans the filename. `NotFound` means the collection is unknown or belongs to another tenant (deliberately indistinguishable).
   - `DELETE /v1/documents/{id}` must add the exclusion with **`SqlSyncStore.add_exclusion(tx, kind, external_id, reason)`**, or take `lock_source_item` itself, in the same tx that removes the document. That advisory lock serializes it against sync's fenced commit, which re-checks exclusions under the same lock. Without it, a sync that is in flight can resurrect an excluded page (a narrow race). For uploads the exclusion key is `('file', str(upload_id))`.
   - `DELETE /v1/connectors/{id}`: E sets `deleting` and destroys the secret, then enqueues `delete_connector` with payload `{"connector_id": ...}`. C2's handler destroys the secret again (idempotent), deletes documents in batches, then deletes the connector row.
5. **Scheduler (whoever owns `list_due_connectors`):**
   - Enqueue `sync_connector` with payload `{"connector_id"}` and dedupe `sync_connector:<id>`, at priority incremental.
   - Enqueue `reconcile_deletes` nightly with payload `{"connector_id"}` and dedupe `reconcile_deletes:<id>`, at priority maintenance.
   - On success, C2 sets `connectors.next_poll_at = now() + poll_interval` (300 s), and only for `active` connectors.
6. **Dependencies (packages/core/pyproject.toml, `ingest` extra):** `pypdf>=5` for PDF support. PDFs are currently rejected as unsupported, and nothing else is needed for that. Once pypdf is added, add a `MIME_PDF` branch in `_sandbox.py` (it caps pages via `max_pages`) and add `MIME_PDF` to `SUPPORTED`. DOCX is implemented with the stdlib (zip + ElementTree; DTDs refused; bounded decompression), so `python-docx` is not required.
7. **Settings (config.py), optional:** `parse_timeout_s` (60), `parse_memory_mb` (1024), `max_upload_mb` (50), `sync_poll_interval_s` (300). The defaults currently live in `ParseLimits` / `SyncPolicy` / `MAX_UPLOAD_BYTES`.
8. **Container:** the parser child runs `sys.executable -I _sandbox.py`. The worker image must keep that file (it ships in the wheel because it is in `src/`). `RLIMIT_AS` is enforced on Linux only; on macOS dev, the CPU rlimit and the wall-clock kill are the backstop.

## Decisions worth reviewing
- **Uploads:** `external_id = str(upload_id)` (one document per upload, excludable by id), and `fetched_at = uploads.created_at`, so a reindex re-ingest is idempotent.
- **Synced blocks:** the frozen `SourceConnector` has no "last_edited of a block" call. Reconcile uses a source's `last_edited_time` when the source id appears in the full listing (a page id). An id it cannot see counts as **changed**, so the dependent is re-enqueued nightly at backfill priority: correct but costs rate budget.
  - Proposed port addition (not made): `SourceConnector.last_edited(ids) -> dict[str, datetime]`.
- **Cursor:** `max(last_edited_time)` of the completed listing (Notion clock, not ours). It is stored as UTC ISO text and compared as `timestamptz` in SQL (GREATEST semantics). Enqueues and the cursor advance commit in one fenced tx.
- **Reconcile:** a confirm_deleted error or `False` means no tombstone; it is retried the next night.
- **delete_connector:** deletes documents in fenced batches of 500, with a heartbeat between batches. Batches commit independently because deletion is idempotent, and only the last tx completes the job.
- **Parser rejections** (type, size, limits, timeout, malformed) raise `ParseRejected(ValidationFailed)` and are permanent.
